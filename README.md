Tujuan utama saya mempelajari Data Science adalah untuk menguasai kemampuan mengeksplorasi, membersihkan, dan menganalisis data mentah yang bervolume besar agar dapat diubah menjadi informasi berharga (actionable insights) yang mendukung pengambilan keputusan berbasis data secara akurat. Melalui kombinasi ilmu statistika, pemrograman Python, dan pemahaman bisnis, proses belajar ini juga bertujuan untuk membangun model prediksi menggunakan algoritma machine learning yang mampu memberikan solusi cerdas, efisien, dan inovatif terhadap berbagai tantangan nyata di industri teknologi saat ini.

Instalasi dan setup menggunakan Google Colab 
Buka salah satu notebook (.ipynb) yang ada di dalam repository ini melalui GitHub.
Ganti URL github.com pada address bar browser Anda menjadi [colab.research.google.com/github/](https://colab.research.google.com/github/).
Notebook akan otomatis terbuka di Google Colab. Pastikan Anda sudah masuk (sign-in) menggunakan akun Google Anda, lalu pilih Runtime > Run all untuk menjalankan seluruh sel.
